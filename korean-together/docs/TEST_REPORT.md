| 12 | **정원 마감** + 결제 중 좌석 임시 확보 → 만료 후 반환 → 늦게 온 결제는 마감 처리 |
| 13 | **취소·환불**: 중복 요청 차단, 초과 금액 거부, 부분 환불(권한 유지) → 전체 환불(권한 자동 종료·링크 비노출), 기록 |
| 14 | 결제 링크(A안): 학습자 신고만으로 등록 안 됨, 금액 불일치 거부, 관리자 확인 후 등록, 중복 확인 차단 |
| 15 | 관리자 2단계 인증: 활성화 후 OTP 없이 관리자 API 불가, 틀린 코드 거부 |
| 16 | CSRF: 사이트 헤더 없는 쓰기 요청 거부 |
| 17 | 비밀번호 재설정: 미연결 상태 그대로 안내, 발송함에 토큰 미저장, 토큰 1회용, 이전 비밀번호 무효 |
| 18 | 이용약관·개인정보 처리방침 미게시 시 결제 차단 |
