# 관리자 이용 안내

관리자 화면 주소: `https://운영도메인/admin`. 학습자 화면과 분리되어 있으며, 관리자 계정으로만 들어갈 수 있습니다.
모든 권한 검사는 서버에서 하므로, 학습자 계정으로는 화면을 열어도 데이터를 볼 수 없습니다.

## 0. 처음 한 번

1. 서버에서 관리자 계정을 만듭니다.
   ```bash
   ADMIN_PASSWORD='10자 이상 비밀번호' npm run create-admin -- 관리자이메일@도메인
   ```
2. `/admin`에 로그인 → **보안(2단계 인증)** 탭 → 인증 앱에 비밀 키 등록 → 6자리 코드로 활성화.
3. 모든 관리자가 설정을 마치면 `.env`에 `ADMIN_REQUIRE_MFA=true`를 넣고 서버를 다시 시작합니다.

## 1. 운영 준비 순서 (권장)

| 순서 | 메뉴 | 할 일 |
|---|---|---|
| 1 | 사이트·운영기관 | 사이트명·핵심 문구, 운영기관명·대표자·사업자 정보·주소·연락처, 이용약관·개인정보 처리방침·환불 안내 입력 |
| 2 | 강사 | 강사 이름·소개·자격·경력 입력 후 ‘공개’ 체크 (자격증 사본은 개인정보를 가린 것만) |
| 3 | 과정·수강료 | 과정별 수강료·통화·횟수·회당 시간·강사·환불 기준 입력 (결제 링크 방식이면 결제 링크도) |
| 4 | 개설반·시간표 | 반 만들기 → 기준 시간대·정원·마감 → 회차 일정과 화상 링크 입력 → 상태 ‘모집 중’ |
| 5 | 현황·연결 상태 | 결제·이메일 연결 상태와 ‘실제 운영 전 확인 항목’ 점검 |

**결제가 열리는 조건** (하나라도 빠지면 학습자 화면에 사유가 표시되고 결제 버튼이 막힙니다)
- 수강료 입력 (비워 두면 ‘추후 안내’)
- 과정 환불 기준 입력
- 이용약관·개인정보 처리방침 게시
- 반 상태 ‘모집 중’, 신청 마감 전, 회차 일정 1개 이상 (녹화 학습 반은 일정 없이 가능)
- 결제서비스 설정 완료 (테스트 모드는 항상 가능)

## 2. 메뉴별 사용법

### 현황·연결 상태
- 학습자 수, 수강 중, 결제 대기, 결제 확인 대기, 환불 요청, 새 문의, 검토 필요 주문
- 통화별 매출(결제 합계·환불 차감 순매출), 반별 수강/정원
- 결제·이메일·2단계 인증 연결 상태, 운영 전 확인 항목(정산 계좌·웹훅·백업은 직접 확인 후 체크)

### 과정·수강료
- ‘회차별 학습 내용’은 한 줄에 하나씩 `한국어 | English` 형식으로 적습니다.
- 수강료를 바꾸면 기록에 남습니다. 결제 대기 중인 주문은 결제 시작 순간의 가격으로 다시 확정됩니다.
- 과정을 숨기려면 ‘비공개’로 바꿉니다. 주문이 있는 과정은 삭제할 수 없습니다.

### 개설반·시간표
- 회차 일정은 한 줄에 하나: `2026-11-03 19:30 | https://zoom.us/j/...`
  시간은 **그 반의 기준 시간대**로 적습니다. 학습자에게는 기준 시간과 학습자 현지 시간이 함께 표시됩니다.
- 화상 링크는 해당 반에 결제 완료·수강 중인 학습자에게만 보입니다.
- 정원은 현재 수강 인원보다 작게 줄일 수 없습니다.
- ‘수강생에게 일정 안내 메일 보내기’로 반 전체에 안내합니다(이메일 서비스 연결 시 발송).

### 주문·결제
- 상태별로 걸러 봅니다: 결제 대기 / 결제 확인 대기 / 결제 완료 / 결제 실패 / 시간 만료 / 취소 / 부분 환불 / 전체 환불.
- **결제 링크 방식**: 학습자가 ‘결제를 마쳤어요’를 누르면 `결제 확인 대기`가 됩니다. 결제서비스 관리 화면에서 입금을 확인한 뒤 ‘결제 확인 후 등록’에 거래번호와 금액을 넣으면 수강이 등록됩니다. 금액이 주문과 다르면 거부됩니다.
- **검토 필요** 표시: 결제 후 정원이 넘쳤거나(over_capacity) 결제사 금액이 주문과 달랐던 경우입니다. 확인 후 환불하거나 ‘검토 완료’를 누릅니다.
- 수강 권한은 ‘수강 권한 종료/복구’로 직접 조정할 수 있으며 모두 기록됩니다.

### 취소·환불
- 학습자가 ‘나의 학습’에서 요청하면 여기에 쌓입니다. 신청 당시 환불 기준이 함께 보입니다.
- 금액을 정해 **승인·환불 처리**를 누르면:
  - 테스트·토스 결제: 서버가 결제서비스에 환불(취소)을 요청하고, 성공한 금액만 반영합니다.
  - 결제 링크 결제: 결제서비스에서 먼저 환불한 뒤 ‘외부 환불 근거’를 입력해야 처리됩니다.
- 전체 환불이면 수강 권한이 자동 종료됩니다. 부분 환불은 ‘수강 권한 종료’를 체크한 경우에만 종료됩니다.
- 반려 시 사유가 학습자에게 표시되고 메일로 안내됩니다(연결 시).

### 출석·진도
- 반을 고르면 학습자별 진도(%)와 회차별 출석 선택 칸이 나옵니다. 선택 즉시 저장됩니다.

### 자료·복습 문제
- 자료는 ‘사용 권한 확보 확인’에 체크해야 등록됩니다. 등록한 자료만 수강생에게 보입니다.
- 반 번호를 비우면 과정 전체 수강생에게, 넣으면 그 반에만 보입니다.

### 문의 / 공지·FAQ / 이메일 발송함 / 변경 기록
- 문의 답변은 학습자의 ‘나의 학습 › 내 문의’에 표시되고, 선택하면 메일로도 보냅니다.
- 이메일 발송함의 ‘미발송(서비스 미연결)’은 실제로 보내지지 않은 메일입니다.
- 변경 기록에는 로그인, 가격·설정 변경, 결제·환불, 수강 권한 변경, 결제 통지 수신이 남습니다. 화면에서 수정·삭제할 수 없습니다.

## 3. 개인정보 다루기
- 학습자 개인정보(이메일·이름·국가·시간대·신청 정보)는 관리자 화면에서만 보입니다. 업무에 필요한 범위에서만 확인하세요.
- 사이트는 카드 정보를 받지 않습니다. 학습자에게 카드 정보를 메일·메신저로 받지 마세요.
- 관리자 계정을 여러 사람이 공유하지 말고 사람마다 만드세요(기록에 처리자가 남습니다).

## 4. 백업과 복구
- 모든 데이터는 `DATABASE_PATH`의 SQLite 파일 하나에 있습니다(기본 `data/korean-together.db`).
- 서버를 잠시 멈추거나 `sqlite3 data/korean-together.db ".backup 'backup-YYYYMMDD.db'"`로 복사본을 만들어 다른 곳에 보관하세요.
