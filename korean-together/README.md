# 한국어로 잇다 · Korean Together

외국인 청년과 시니어를 위한 온라인 한국어 교육 운영 사이트입니다.
교육과정 소개 → 무료 체험 → 수강 신청 → 온라인 결제 → 수업 참여 → 복습 → 운영자 관리까지 한 서버에서 이어집니다.

> 확인되지 않은 사업자 정보·강사 경력·수강료·시간표는 **비워 둔 상태**로 시작합니다.
> 공개 화면에는 ‘추후 안내’ / ‘등록 예정’으로 표시되고, 수강료·환불 기준·약관이 확정되기 전에는 결제가 열리지 않습니다.

## 바로 실행

필요: Node.js 22.5 이상 (외부 패키지 설치 없음 — 내장 SQLite 사용)

```bash
cd korean-together
cp .env.example .env        # 필요 시 값 수정 (기본: 테스트 결제, 이메일 미연결)
npm start                   # http://localhost:8080  (학습자)  /admin (관리자)
ADMIN_PASSWORD='10자이상비밀번호' npm run create-admin -- admin@example.com
```

`.env` 파일은 직접 읽지 않으므로, 운영 서버에서는 환경변수로 넣거나 `node --env-file=.env server/index.js`로 실행하세요.

## 구성

| 경로 | 내용 |
|---|---|
| `server/` | Node.js HTTP 서버 (의존성 없음) |
| `server/db.js` | SQLite 스키마 — 회원, 과정, 반, 회차, 주문, 결제 통지, 수강, 출석, 진도, 자료, 문의, 환불, 이메일, 변경 기록 |
| `server/orders.js` | 주문·좌석 임시 확보·결제 승인·중복 방지·환불 반영 핵심 로직 |
| `server/payments.js` | 결제서비스 어댑터: 테스트 / 결제 링크 / 토스페이먼츠 / 엑심베이(구현 대기) |
| `server/email.js` | 이메일 안내 (미연결 시 ‘미발송’ 기록) |
| `server/routes/site.js` | 공개·회원·신청·결제·나의 학습 API |
| `server/routes/admin.js` | 관리자 API (역할 + 2단계 인증 서버 검증) |
| `public/` | 학습자 화면(`index.html`)과 관리자 화면(`admin.html`) |
| `test/api.test.js` | 서버 테스트 (`npm test`) |
| `test/e2e.mjs` | 브라우저 종단 테스트 (Playwright) |
| `docs/` | 관리자 이용 안내, 외부 서비스 연결 목록, 테스트 결과 |

## 학습자 화면

- 메뉴: 홈 / 교육과정 / 무료 체험 / 강사 소개 / 수업 신청 / 나의 학습 / 도움말
- 한국어·영어 전환 (선택한 과정·입력 중인 신청 정보 유지), **글자 크게**(20px → 24px), **쉬운 화면**(수업 찾기 / 내 수업 / 도움 받기)
- 과정 추천: 나이가 아니라 한국어 수준·학습 목적·희망 속도 기준 (학습 안내용이며 공식 인증이 아님을 표시)
- 무료 체험 ‘첫 인사 배우기’: 표현 → 뜻·상황 → 발음 듣기(반복·느리게) → 따라 말하기 → 확인 문제 → 과정 추천.
  기기의 한국어 음성 지원 여부를 확인하고, 없으면 안내 후 발음 표기로 연습합니다.
- 나의 학습: 다음 수업(기준·현지 시간), 수업 참여하기, 이어서 학습, 회차별 자료, 복습 문제, 즐겨찾는 표현, 진도, 출석, 결제 내역·확인서, 환불 요청, 문의

## 정적 미리보기 (서버 없이)

`npm run export-static`은 공개 데이터 스냅숏(`public/data/public-snapshot.json`)을 만듭니다.
`public/` 폴더를 GitHub Pages 등에 올리면 과정 소개와 무료 체험은 볼 수 있고, 회원가입·신청·결제는 동작하지 않는다는 안내가 화면에 표시됩니다.
