# PPT 표준 서식 — Green-Navy 강의 템플릿

이 스킬은 서식만 정의한다. 슬라이드 내용은 사용자가 제공하며, **제공한 내용은 순서와 문장을 그대로 사용하고 임의로 요약·추가·수정하지 않는다.** 각 슬라이드에 맞는 레이아웃을 고르고 아래 서식을 적용한다.

좌표 단위는 인치(in)이며 기준점은 슬라이드 왼쪽 위다.

## 워크플로
1. 사용자가 준 슬라이드 내용을 순서대로 나열한다. 문장은 고치지 않는다.
2. 각 슬라이드의 성격(표지, 간지, 설명, 이미지, 목록, 비교, 워크북, 휴식, 마무리 등)을 보고 레이아웃 A~R 중 하나를 고른다.
3. 같은 레이아웃을 3장 연속 쓰지 않도록 배치한다.
4. 공통 프레임과 레이아웃 서식을 적용해 .pptx를 만든다.
5. 제작 후 모든 슬라이드를 이미지로 렌더링해 글자 넘침, 겹침, 쪽번호를 점검하고 수정한다.

## 1. 슬라이드 설정
- 크기: 16:9 와이드 **13.333 × 7.5 in** (33.87 × 19.05 cm)
- 배경: 본문 슬라이드 흰색 #FFFFFF / 간지·휴식 슬라이드 크림 #FBF7EF
- 좌우 여백 0.6 in, 콘텐츠 너비 **12.13 in** (x 0.6 ~ 12.73)
- 콘텐츠 영역: y 1.5 ~ 6.75 in

## 2. 글꼴 (4종 외 사용 금지)
| 용도 | 글꼴 | 대체 글꼴 |
|---|---|---|
| 제목·카드 제목·숫자 | **HY견고딕** | 맑은 고딕 Bold |
| 본문·인용·강조 문장 | **HY견명조** (항상 굵게) | 나눔명조 ExtraBold |
| 머리글·바닥글·태그·출처 | **맑은 고딕** (보통) | – |
| 카드 속 보조 설명 | **나눔고딕 ExtraBold** | 맑은 고딕 Bold |

- 본문 최소 20pt, 기본 24~28pt, 한 줄 메시지 28~36pt

## 5. 레이아웃 유형

**[A] 표지** — 흰 배경, 가운데 정렬
- 로고 0.6, 0.46, 폭 2.6
- 제목 HY견고딕 54pt 굵게 #222222 (y 1.9) / 부제 HY견명조 26pt 굵게 (y 3.2)
- 가는 선 1pt #999999 (x 1.2, y 4.15, 길이 10.9) → 인용문 HY견명조 20pt 굵게 #002060 (y 4.3)
- 발표자 HY견명조 20pt 굵게 #222222 오른쪽 정렬 (y 5.9) → 가는 선 (y 6.3) → 행사명 맑은 고딕 14pt #6B6B6B (y 6.45)

**[B] 간지** — 배경 #FBF7EF, 머리글·태그·쪽번호 없음

**[Q] 마무리** — 머리글·바닥글 없음, 가운데 정렬

**[R] 전면 이미지/영상** — 여백 없이 가득 채움, 공통 프레임 없음

## 6. 서식 규칙
- 제목 색: 설명 슬라이드는 네이비(#002060), 워크북·실천·마무리는 딥그린(#1E4D3A)
- 쪽번호는 실제 슬라이드 순서와 일치시킨다
- 제목에 마침표를 쓰지 않고, 제목 아래 밑줄 장식을 넣지 않는다
- 박스는 모두 둥근 사각형, 핑크 띠만 직사각형으로 한다. 핑크 띠는 슬라이드당 1개
- 강조는 색과 굵기로만 한다 (밑줄·기울임·그림자·그라데이션·장식 이모지 사용 안 함)
- 색 강조는 슬라이드당 1~2곳
- 출처 표기는 맑은 고딕 11~13pt #6B6B6B
- 사진 자리는 회색 점선 상자에 "[이미지: 설명]"으로 표시한다
- 글자가 상자를 넘치면 20pt 아래로 줄이지 말고, 상자를 키우거나 슬라이드를 나눈다. 나눌 때도 문장은 고치지 않는다
- 같은 레이아웃을 3장 연속 쓰지 않는다
- 제작 후 모든 슬라이드를 이미지로 렌더링해 글자 넘침·겹침·쪽번호를 점검하고 수정한다

## 7. 슬라이드 내용 입력
사용자가 슬라이드 내용을 제공하면 위 규칙 아래에 순서대로 배치한다. 내용이 아직 없으면 내용을 요청한다.
