# Veranda Pottery 홈페이지

프놈펜 크메르 전통 도예 공방 **베란다 포터리**의 독립 홈페이지입니다. 다른 사이트와 섞이지 않도록 이 폴더 하나에 필요한 파일이 모두 들어 있어, 폴더째 새 저장소로 옮겨도 그대로 동작합니다.

## 구성

| 파일 | 역할 |
|---|---|
| `index.html`, `styles.css`, `app.js` | 공개 홈페이지 (영어/한국어 전환) |
| `pottery-data.js` | Facebook 주소, 수업 종류별 진행 단계, 데이터 불러오기 (두 화면 공용 설정) |
| `data/pieces.json` | 작품 진행 데이터 (공개 파일) |
| `studio.html`, `studio.js` | 공방 관리 도구: 작품 등록, 단계 갱신, QR 수령 카드 인쇄, 데이터 내보내기 |
| `vendor/qrcode.js` | QR 생성 라이브러리 (qrcode-generator 1.4.4, MIT) |
| `assets/` | 베란다가 Facebook에 올린 워크숍 사진·포스터 |

## 홈페이지 메뉴

1. **Workshops**: 공방 상시 수업($10, $15)과 지난 팝업 워크숍
2. **My piece (내 작품)**: 작품 번호로 진행 단계, 날짜, 사진, 메모, 완성 예정일을 조회. Facebook 공유와 링크 복사 지원
3. **Invite us**: 학교·카페·단체 출장 수업 문의 (Messenger 연결)
4. **News**: Facebook 페이지 피드를 그대로 보여줌. 공방이 글을 올리면 자동 반영
5. **Visit**: 주소, 전화, 지도

## 작품 진행 단계

| 수업 | 단계 |
|---|---|
| 캄보디아 전통 도예 | 빚기 → 건조 → 전통 소성 → 수령 가능 → 수령 완료 |
| 물을 담는 도자기 | 빚기 → 건조 → 초벌 → 유약 → 재벌 → 수령 가능 → 수령 완료 |
| 페인팅 & 식물 | 만들기 → 당일 수령 |

단계 이름과 설명은 `pottery-data.js`의 `STAGES`에서 바꿉니다.

## 공방 운영 방법

### 방법 A: 관리 도구 + GitHub (기본)

1. `studio.html`을 열고 수업 직후 작품을 등록합니다. 저장하면 QR이 들어간 수령 카드가 뜨니 인쇄해서 참가자에게 줍니다.
2. 단계가 바뀌면 목록에서 **다음 단계 ▶**를 누릅니다. 사진과 메모는 **수정**에서 넣습니다.
3. **pieces.json 내려받기**를 누른 뒤, GitHub에서 `veranda-pottery/data/pieces.json`을 이 파일로 덮어 올립니다. 1~2분 뒤 홈페이지에 반영됩니다.

관리 도구의 변경 내용은 그 기기 브라우저에만 임시 저장됩니다. 반드시 3번까지 해야 홈페이지에 나타납니다.

### 방법 B: Google 시트 (휴대폰으로 바로 갱신)

1. Google 시트 첫 행에 `code, maker, title, class, stage, made, pickup, note, photo, history`를 적습니다. 관리 도구의 **시트용 CSV 복사**로 기존 데이터를 붙여넣어도 됩니다.
2. 시트에서 **파일 → 공유 → 웹에 게시 → CSV**를 고르고 링크를 복사합니다.
3. `pottery-data.js`의 `sheetCsvUrl`에 그 링크를 붙여넣습니다.

이후에는 시트를 고치면 바로 홈페이지 조회에 반영됩니다. `history` 칸은 `drying:2026-09-22|firing:2026-10-05`처럼 적습니다.

## 개인정보

`pieces.json`과 게시된 시트는 누구나 열어볼 수 있습니다. 참가자 이름은 이니셜이나 이름만 쓰고, 전화번호·전체 이름은 넣지 않습니다. 작품 번호는 무작위로 만들어져 다른 사람의 번호를 짐작하기 어렵습니다.

## 운영 전 확인할 것

- `data/pieces.json`의 `VP-DEMO-…` 예시 2건은 체험용입니다. 실제 운영 전에 지우거나 그대로 체험용으로 둡니다. 관리 도구는 예시를 자동으로 제외합니다.
- Facebook 피드는 공방 계정이 **공개 Facebook 페이지**여야 보입니다. 피드 자리가 비어 보이면 페이지 공개 설정을 확인하세요. 옆의 Facebook 버튼과 Messenger 문의 버튼은 설정과 상관없이 동작합니다.
- 크메르어 번역은 원어민 검수 후 `app.js`의 `I18N`에 `km`을 추가해 넣을 수 있습니다.
