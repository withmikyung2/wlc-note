# WLC 2급 16강 강의 PPT

교재(2026 통합개정판) 제N장 = 제N강, 회차당 3시간(1교시 50분 · 휴식 10분 · 2교시 50분 · 휴식 10분 · 3교시 60분).

## 구성
- `lib.js` — 공통 디자인·슬라이드 유형 엔진(표지, 질문, 카드, 비교, 흐름, 표, 활동, 퀴즈, 휴식, 다음 회차 예고 등)
- `roadmap.js` — 16강 로드맵
- `lectureNN.js` — 회차별 슬라이드 데이터(분 단위 시간 배분, 교재 위치, 강사 노트)
- `out/` — 생성된 .pptx

## 회차 공통 흐름
열기(표지·로드맵·오늘의 3시간·오프닝 질문·학습목표) → 1교시 → 휴식 → 2교시 → 휴식 → 3교시(실습·나눔·퀴즈) → 학습점검·핵심정리·과제·마지막 질문 → **마지막 장: 다음 회차 예고**

## 빌드
```bash
npm install pptxgenjs react react-dom react-icons sharp jszip
PPTX_SKILL=<pptx 스킬 경로> node build.js 01
```
빌드 시 슬라이드별 분 배분 합계(180분)와 글자 넘침 경고가 출력됩니다.
